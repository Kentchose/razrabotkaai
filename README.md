# Сайт «Разработка - ИИ» (рабочее название)

Статический сайт на HTML/CSS: услуги по внедрению ИИ-помощников в бизнес. 46 страниц, без сборки и без базы данных.

## Структура
- `index.html` — главная
- `uslugi/` — решения, `otrasli/` — отрасли, `blog/` — статьи
- `tarify/`, `etapy/`, `bezopasnost/` — подробные страницы тарифов, этапов и безопасности
- `assets/style.css` — все стили (цвета заданы в начале файла)
- `send.php` — приём заявок с формы (нужен PHP на хостинге)

## Что заменить перед публикацией
1. Название «Разработка - ИИ» — на своё (поиск по всем файлам).
2. Заглушки `[ ... ]`: контакты, цены, сроки, реквизиты, кейсы, отзывы, команда.
3. В `send.php` указать свой e-mail в переменной `$to`.
4. Текст политики конфиденциальности проверить у юриста.

Инструкция по размещению на хостинге (Beget) — в `DEPLOY.txt`.
